Release notes for the **Esper Genesis Threats Database** module.

The current release, 1.0.2, requires Foundry VTT v14 and the dnd5e system
(minimum 5.0.0, verified against 5.3.3). As of 1.0.2 the Core Manual is no longer
required, though the two modules are designed to be used together.

---

## 1.0.2

- The Threats Database no longer requires the Esper Genesis Core Manual to be installed. Icons, power links and summoned creatures now point at the module's own independent copies.
- Fixed missing icons across threats, powers and effects so they link to their correct file paths.
- Fixed esper power links on threats and their effects to be independent of the Core Manual.
- Added Force Globe for the Lorendi Aetherwalker's summoning ability.
- Fixed links to summoned and related creatures such as the Forged Construct, and the condition effects on Cirrus Mecharoid, Kotatu, Kreidren, Seethespawn and others.

## 1.0.1

- When the Esper Genesis Core Manual is active (v1.0.3 or later), Astrophysics and Mechanics have been updated to match a corresponding dnd5e skill with the same ability. This affects Expert Pilot, Field Engineer, Hadraxis Guardian, Hadraxis Noble, Heavy Centurion, Lorendi Machinist, Machinist, Master Melder and Melder Savant.
- Existing world actors are already updated by the Core Manual's one-time update prompt.
