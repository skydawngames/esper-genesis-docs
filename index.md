Release notes for the official **Esper Genesis** modules for Foundry Virtual
Tabletop, published by [Skydawn Game Studios](https://skydawngames.com).

Modules are installed and updated as Foundry packages. These
pages are created to inform on recent changes and updates for each release.

## Modules

| Module | Current version | Release notes |
| --- | --- | --- |
| Esper Genesis Core Manual | 1.2.1 | [Changelog]({{ '/changelogs/core-manual' | relative_url }}) |
| Esper Genesis Threats Database | 1.0.3 | [Changelog]({{ '/changelogs/threats-database' | relative_url }}) |
| Esper Genesis Master Technician's Guide | 1.0.1 | [Changelog]({{ '/changelogs/master-technicians-guide' | relative_url }}) |

**Core Manual** contains the full ruleset, including species, classes, backgrounds, feats,
esper powers, equipment and starships.

**Threats Database** is a standalone product. As of v1.0.2 it no longer requires
the Core Manual to be installed, though both modules are designed to be used together.

**Master Technician's Guide** is the core game master supplement, with rules for tailoring
game mechanics, new options for gear and starships, and tools for building locations and
encounters. It requires the Core Manual, version 1.2.0 or later.

## Requirements

All three modules currently require v14 of the **Foundry VTT** and the **dnd5e** game system. The Core Manual and Master Technician's Guide are verified with dnd5e v6.0.6; the Threats Database is verified with v5.3.3.

## Support

For questions about the game itself, visit
[espergenesis.com](http://espergenesis.com). If there's a specific issue with a Foundry module, please note the module version from the changelog page above when reporting it.
