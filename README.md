# Esper Genesis for Foundry Virtual Tabletop

Public release notes for the Esper Genesis modules for Foundry Virtual Tabletop,
published by Skydawn Game Studios.

This repository contains **documentation only**. No module code, compendium
content or artwork lives here.

## What is here

```
_config.yml                    site configuration
index.md                       site landing page
changelogs/
  core-manual.md               Esper Genesis Core Manual
  threats-database.md          Esper Genesis Threats Database
assets/css/style.scss          theme overrides
```

## Publishing

The site is built and hosted by GitHub Pages. There is nothing to install and
nothing to run locally.
